# taskbar_dock_mode
Um mod para o [Windhawk]no Windows 11 que faz a barra de tarefas se comportar como o Dock do macOS: ela fica permanentemente desenhada por cima de todas as janelas e deixa de reservar espaço na Work Area do monitor — preservando 100% do visual nativo do Windows (Mica, Acrylic, cantos arredondados e animações não são tocados).
